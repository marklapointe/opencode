131-bus.md

Directory: src/bus/

Overview: In-process event bus used for publishing and subscribing to typed events across the OpenCode runtime.

- bus-event.ts
  - Exports: Event definitions via BusEvent.define; payload schemas for events
  - Role: Central registry of event types with typed payload schemas used by the bus

- index.ts
  - Exports: Bus.Service with publish/subscribe APIs; a global instance state; default runtime layer; helper wrappers for subscribing to events
  - Role: Provides the runtime event bus that coordinates across modules (e.g., storage, session, MCP, etc.)

- global.ts
  - Exports: GlobalBus, used to emit system-wide events to external observers

- The bus system creates a per-directory state and per-event-type PubSub streams; it also publishes a server-disposed event when a workspace ends to ensure subscribers clean up.

End of 131-bus.md
