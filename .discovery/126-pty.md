126-pty.md

Directory: src/pty/

Overview: Terminal PTY subsystem providing dynamic terminal sessions, sockets, and a bridge to the underlying process manager.

- pty.ts
  - Exports: Disp, Exit, Opts, Proc types; core API for a PTY process wrapper
  - Role: Defines the primitive interfaces used to spawn, resize, write and listen to data from a PTY process

- pty.node.ts (adapter for node runtime)
  - Exports: adapter surface for Node runtime (not shown in full here)

- index.ts
  - Exports: Info, CreateInput, UpdateInput, Event, Interface, Service; a large Layer that wires PTY lifecycle (create/remove/list/connect) and terminal data dispatch via Bus
  - Role: Provides a high-level API to manage terminal sessions and stream data to and from browsers or clients

- input.ts, schema.ts, pty.bun.ts
  - Expose definitions for input schemas and runtime adapters for Bun/Node integrations

- Core behavior described at a high level: create PTY sessions, manage IO, resize, and close sessions, and notify via Bus events.
