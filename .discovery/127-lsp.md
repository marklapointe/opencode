127-lsp.md

Directory: src/lsp/

Overview: Language Server Protocol integration framework. Provides multiple servers (typescript, vue, eslint, biome, etc.), a proxy/launch mechanism, and a client to communicate with LSP servers.

- server.ts
  - Exports: LSP server runners and integration glue for language servers (deno, typescript, vue, eslint, gopls, etc.)
  - Role: Spawns and coordinates LSP servers per workspace, wires initialization data

- server.ts, client.ts, diagnostic.ts, language.ts, launch.ts
  - Roles: Core LSP backend, client communication, diagnostic reporting, language server discovery, and launching logic

- lsp.ts
  - Exports: LSP Service with state tracking, dynamic server provisioning, client management, and a large array of methods: init, status, hasClients, touchFile, diagnostics, hover, definition, references, implementation, documentSymbol, workspaceSymbol, prepareCallHierarchy, incomingCalls, outgoingCalls
  - Pattern: Effect-based DI to configure and manage multiple LSP servers per project

- Other files (diagnostic.ts, language.ts, launch.ts) provide supporting types and helpers for server behavior and language-specific wiring
