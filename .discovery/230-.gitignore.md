File: packages/console/app/.gitignore

Tree:
- [config] ignore patterns for build outputs and deployment artifacts
- [pattern] dist → ignore built distribution directory
- [pattern] .wrangler, .output, .vercel, .netlify → ignore deployment artifacts
- [pattern] app.config.timestamp_*.js → ignore generated config files
- [pattern] .env, .env*.local → ignore environment files
- [pattern] /node_modules → ignore dependencies directory
- [pattern] /.idea, .project, .classpath, *.launch, .settings/ → ignore IDE/editor config
- [pattern] gitignore → ignore local gitignore (self-reference example)
- [pattern] public/sitemap.xml → ignore sitemap in public assets
- [pattern] .DS_Store, Thumbs.db → ignore system files

Description:
- Standard ignore file for a mixed frontend/build environment with multiple deployment targets.

Data Flow:
- Not consumed at runtime; used by git to exclude files from versioning.

Side Effects:
- Ensures local builds and deployments ignore generated artifacts.
