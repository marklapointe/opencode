128-mcp.md

Directory: src/mcp/

Overview: Model Context Protocol (MCP) integration, including remote/local MCP connectivity, tool translation, and OAuth flows.

- index.ts
  - Exports: MCP Service, layer, and export * as MCP from "." namespace pattern
  - Role: Coordinates MCP clients, tools, prompts, resources, and authentication flows

- oauth-provider.ts, oauth-callback.ts, auth.ts, auth.ts (and other MCP modules)
  - Roles: OAuth flow handling, callbacks, token management, and local/remote MCP authentication surfaces
- The MCP system supports dynamic tool discovery, transport management, and browser-based OAuth flows, with a focus on remote MCP servers.

- main pattern: use of Effect-based DI and Layer composition to wire MCP services into the runtime
