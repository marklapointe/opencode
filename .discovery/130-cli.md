130-cli.md

Directory: src/cli/

Overview: Command-line interface layer and UI bindings for running and debugging the OpenCode backend.

- heap.ts, error.ts, ui.ts, upgrade.ts, logo.ts
  - Roles: CLI runtime helpers, error formatting, UI shell, and upgrade flow hooks
- cmd/**
  - Subcommands for various operations (web, upgrade, uninstall, etc.)
- The CLI uses a mix of runtime helpers and UI components to present a terminal UI, with commands wired into the underlying DI/runtime layers.

- The files along with templates under cli/cmd/tui/ provide a TUI experience and a bridge to the underlying server/backend.
